
# Elektronikë

## Përshkrimi i Repository-t

Ky repository është krijuar në kuadër të lëndës **Elektronikë** dhe shërben për organizimin dhe dorëzimin e detyrave, ushtrimeve dhe punëve praktike të kërkuara gjatë zhvillimit të kësaj lënde.

Në këtë repository do të publikohen materialet dhe detyrat e realizuara gjatë semestrit, duke përfshirë:

- Detyra teorike dhe praktike.
- Eksperimente laboratorike.
- Matje dhe analiza të qarqeve elektronike.
- Ushtrime të realizuara në Jupyter Notebook.
- Përfundime dhe rezultate nga eksperimentet.

## Qëllimi

Qëllimi i këtij repository është dokumentimi i punës së realizuar gjatë lëndës së Elektronikës, si dhe ruajtja dhe organizimi i detyrave të kërkuara.

## Organizimi

Materialet do të organizohen sipas detyrave dhe eksperimenteve përkatëse, në mënyrë që të jenë të lehta për t'u gjetur dhe shqyrtuar.
